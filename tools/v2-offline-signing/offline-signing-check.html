Offline Signing Check

At the counter the student's phone signs a check-in with its session key, often in a basement with no signal. This page runs that signing on your phone with the network off and checks the bytes against the contract-verified SDK.

Checking network Secure context WebCrypto IndexedDB

  1. Create a session key

    Generates a secp256k1 key, encrypts it with a non-extractable AES-GCM key, and stores both in this phone's IndexedDB. Do this once, with the network on or off.

    No session key on this phone yet.

  2. Turn on airplane mode

    Switch off Wi-Fi and mobile data. The network pill at the top turns green and reads Offline. Keep this page open; don't reload it.

  3. Run the signing test

    Reloads the key from IndexedDB, decrypts it, signs a check-in, verifies a tablet signature, and counts any network requests made while it runs.

  4. Save the result

    Turn the network back on, name this phone, and save. Results from every phone collect in the log below, and Claude reads them from there.
